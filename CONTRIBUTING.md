# Contributing

Thanks for helping keep this list useful.

## What belongs here

- Offline / local-first OCR tools
- Bank-statement or financial-document digitization tools
- Privacy-first PDF → structured data pipelines
- Related libraries, models, and benchmarks that can run without sending documents to a third-party cloud API

## What does not

- Pure SaaS OCR with no local option
- Tools that require uploading bank statements to an unknown third party as the only path
- Spam, affiliate dumps, or unverified "AI wrappers" with no repo

## How to add an entry

1. Open a PR editing `README.md`.
2. Keep the section order.
3. Use this format:

```md
- [Name](https://github.com/owner/repo) - One-line description. Optional note on offline/local support.
```

4. Prefer projects with a public source repo.
5. Do not invent star counts or benchmarks.

## Review notes

Maintainers may edit wording for clarity and move items between sections.
